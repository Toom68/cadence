## Download Cadence @VERSION@

| Your computer | Download | |
|---|---|---|
| **Windows 10 / 11** (64-bit) | `Cadence-@VERSION@-windows-x64-setup.exe` | Installs for your user account — no admin needed. Adds a Start menu entry, opens `.cadence` songs on double-click, and **updates itself** from then on. |
| **macOS 11+** (Apple Silicon & Intel) | `Cadence-@VERSION@-macos-universal.dmg` | Open it and drag Cadence into **Applications** — updates install from there with one click. |
| Windows, portable | `Cadence-@VERSION@-windows-x64.zip` | Unzip anywhere and run `Cadence.exe`. No installer, no automatic updates. |

Already have Cadence? It offers this update by itself (or use **Help → Check for Updates…**).

**First launch:** these builds are not code-signed yet. On Windows, SmartScreen may say "Windows protected your PC" — click **More info → Run anyway**. On macOS, right-click Cadence and choose **Open** the first time.

Every download has a `.minisig` signature. Cadence checks it against its built-in release key before installing any update, so an altered file is never installed.
